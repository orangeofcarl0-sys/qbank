# README visual asset provenance

All files in this directory were created specifically for the qbank project from the
repository's synthetic `examples/public-demo` content:

- `studio-main-light.png`, `studio-main-dark.png`, and `studio-assets-dark.png` are generated
  by `scripts/capture-ui.py` from qbank Studio;
- `data-architecture.svg` and `safe-workflow.svg` are self-authored project diagrams.

They contain no third-party screenshots, real examination material, user names, account data,
or local machine paths. They are distributed under the repository's MIT License.
