# 功能文档

本目录保存跨 CLI、Studio、MCP、数据与失败语义的单项功能契约。

- 新功能实现前，从 [`_template.md`](_template.md)建立文档，状态设为 `proposed`。
- 实现完成后更新实际入口、测试、迁移结论和限制，状态设为 `implemented`。
- 被替代或撤回的文档保留背景，并标记 `superseded` 或 `withdrawn`。
- 当前集成入口总览见 [`capability-matrix.md`](capability-matrix.md)。
- 轻量资料入库与固定 TeX 正式交付物的需求见
  [`source-qbank-deliverables.md`](source-qbank-deliverables.md)。

功能文档不是发布说明的替代品。用户可见变化仍须进入 CHANGELOG，重要架构决定仍须进入
ADR。
