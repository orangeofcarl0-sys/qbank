QBank Studio 0.3.0-beta.1 portable

Keep qbank-studio.exe, qbank-sidecar.exe, and WebView2Loader.dll in this
directory. QBank Studio stores no question-bank data inside the application
directory. Close the application before moving or deleting this directory.

The application requires Microsoft Edge WebView2 Runtime 109.0.1518.0 or newer.
This alpha build is unsigned. Verify the published SHA-256 before running it.
